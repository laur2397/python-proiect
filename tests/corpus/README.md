# Corpusul de test

Cele 18 grupuri sunt descrise in `docs/spec/SPEC_06_plan_de_testare.md`,
capitolul 2. Fisierele mari nu intra in git — vezi `.gitignore`.

**Regula care face diferenta:** fiecare fisier de test vine cu rezultatul
asteptat scris de mana, intr-un fisier `.expected` de lângă el. Fara
referinta scrisa de om, un test de OCR nu verifica nimic: compara o ieșire
cu ea insasi.

Ce nu are ce cauta aici: documente cu date personale reale, si documente la
care nu avem drepturi. Documentele romanesti de test se construiesc din
formulare publice si texte proprii, apoi se tipăresc si se scaneaza.

Pragurile de calitate pe care corpusul trebuie sa le dovedeasca sunt in
acelasi fisier, capitolul 3.
