# Cerintele de sistem ale DocuLens (Y-002…Y-006)

| | Minim | Recomandat |
|---|---|---|
| Sistem | Windows 10 sau Windows 11, 64 de biti (si Windows Server 2016 sau mai nou) | Windows 11, 64 de biti |
| Procesor | x64, 1 GHz, 2 nuclee | x64, 2 GHz, 4 nuclee sau mai multe |
| Memorie (RAM) | 4 GB | 8 GB |
| Disc | 1,5 GB pentru instalare plus 2 GB liberi pentru lucru | SSD, 10 GB liberi pentru dosare mari |
| Ecran | 1366×768, scalare 100…200 % | 1920×1080 |
| Scaner | WIA (scanere si multifunctionale) | WIA, cu alimentator automat |

- Nu e nevoie de internet, de activare, de Microsoft Office sau de .NET (Y-001,
  Y-007, Y-012).
- Pe servere de terminal (Windows Server RDS, Citrix) fiecare utilizator conectat
  ruleaza instanta lui (Y-005); Hot Folder ruleaza numai cat utilizatorul e
  conectat (S-005).
- Limba interfetei (romana sau engleza) trebuie sa fie suportata de sistem (Y-002);
  diacriticele romanesti cer fonturile standard ale Windows.
- Scanarea prin TWAIN nu e inca facuta (faza 6d, INCOMPLET); se foloseste WIA.
